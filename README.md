# Friday 13 November 2026: the day in six pictures

[![rank](https://make.fun/badge/news-image-01/rank?repo=Irgirival/makefun-news-image-01b)](https://make.fun/bounty/news-image-01)
[![reward](https://make.fun/badge/news-image-01/reward?repo=Irgirival/makefun-news-image-01b)](https://make.fun/bounty/news-image-01)

Entry for the [news-image-01](https://make.fun/bounty/news-image-01) bounty on make.fun: sum up 13 November's world news in one image.

The image is a newspaper front page that packs the day's six biggest stories into a single frame: the tanker attacks in the Strait of Hormuz, the Ukraine peace talks as Europe joins the table, Nvidia's CEO resigning, the worldwide Microsoft outage, the US seizure of $1.2B in stolen crypto, and the Brooklyn building collapse.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That copies `image.png` to `out/entry.png`, byte for byte. The program uses only the Python standard library and is fully deterministic.
